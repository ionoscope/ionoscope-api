# Контракт для фронтенда, API 0.2.0

`openapi.json` — схема для генерации клиента. `forecast.example.json` — компактный
мок графика и таблицы с пропуском наблюдения. Все примеры проверяются по JSON Schema.
Пересоздать файлы из каталога API: `python -m scripts.export_contract`.

Готовы: единые ошибки, типы и operationId, история и таблица, роли, параметры,
forecast_id, сроки свежести, метаданные станций, CORS и SSE объяснений.
Прогноз кэшируется независимо от роли; объяснение — по forecast_id и роли.
Поле model_version сообщает версию загруженной ML-модели, независимо от версии API.

В инфраструктуре добавлены сервис статики, проксирование API, настройки SSE
и ограничение частоты запросов объяснения. Каталог статики должен содержать index.html.
Для объяснений нужно настроить URL, модель и при необходимости ключ LLM-провайдера.
Без провайдера SSE возвращает explanation_unavailable, прогноз остаётся доступен.

Проверка сохранённой истории: TR169, DB049, JR055 имеют данные с 17 октября 2026,
12:15 UTC до 25 октября 2026, 12:00 UTC. Истории достаточно для суточного графика,
но на 3 ноября она просрочена. После запуска сборщика нужна проверка свежих данных.
Data API поддерживает allow_partial=true: отсутствующие точки становятся null.

Docker Compose dev/prod проверены командой config. Запуск контейнеров, проверка
nginx на работающем контуре и реальный LLM-вызов не выполнены: Docker Engine
недоступен, провайдер не настроен. SSE проверен на имитаторе провайдера, включая
поток, кэш по ролям, отказ и обрыв соединения.
